# Household income

Official household income figures, one file for each source and reference year. Start at
`index.json`: it lists each source, its newest year and the path and checksum of every file. A file
is `<source>/<yyyy>.json`. Each row has a measure, a place, a figure and its currency. The measure
says what the figure is (a median per adult, or a mean per head). Never compare one measure with
another. Each file says who to credit.
